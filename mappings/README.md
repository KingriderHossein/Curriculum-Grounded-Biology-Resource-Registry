# Optional Curriculum Mappings

This directory is intentionally secondary.

A curriculum mapping may connect an external course/degree to part of a Subject roadmap, for example:

```text
External curriculum course
        ↓ maps to
CELL-BIOLOGY
        ↓
selected concept IDs / roadmap stages
```

Mappings must never duplicate Subject resources or redefine the scientific roadmap.

No curriculum mapping is required for a Subject to exist in this registry.
