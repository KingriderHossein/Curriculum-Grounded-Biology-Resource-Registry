# آناتومی — ⁦Anatomy⁩

> **وضعیت:** ⁦Complete⁩ — مسیر نظری شامل ۴ مرحله عمومی، ۹ شاخه تخصصی و ۱۳ جایگاه منبع است.

این مسیر آناتومی ماکروسکوپی انسان را از زبان و جهت‌یابی آناتومیک تا نواحی بدن و روابط فضایی ساختارها دنبال می‌کند. آموزش تشریح عملی، مهارت‌های بالینی، تکنیک‌های تصویربرداری و پروتکل‌های آموزشی کاداور خارج از دامنه Registry هستند.

## مرحله پایه


### ⁦Anatomy and Physiology 2e⁩

**مناسب برای:** دانشجویی که زبان جهت‌یابی آناتومیک و نمای کلی دستگاه‌ها را کامل به یاد ندارد.

**دلیل انتخاب:** بدون ورود مستقیم به متن سنگین، اصطلاحات و نقشه کلی بدن را تثبیت می‌کند.

**شیوه مطالعه:** فصل مقدماتی و مرور دستگاه‌ها را هدفمند بخوانید؛ کل کتاب لازم نیست.

**ادامه مسیر:** سپس Gray's Anatomy for Students را به‌صورت ناحیه‌ای شروع کنید.
