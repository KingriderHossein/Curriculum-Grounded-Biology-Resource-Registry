# بیوشیمی | ⁦Biochemistry⁩

این صفحه یک **مسیر یادگیری نظری بیوشیمی** است؛ از پیش‌نیازهای شیمیایی و مولکولی تا مطالعهٔ عمیق آنزیم‌ها، زیست‌انرژی، متابولیسم و شاخه‌های تخصصی.  
هدف این نیست که فقط چند کتاب مشهور معرفی شوند؛ باید روشن باشد **از کجا شروع کنید، هر منبع را چرا بخوانید، چگونه از آن استفاده کنید و بعد از آن به کجا بروید**.

> **دامنه:** فقط منابع نظری. پروتکل، راهنمای آزمایشگاهی، ⁦SOP⁩، روش خالص‌سازی و آموزش عملی در این مسیر وارد نمی‌شوند.

# شاخه‌های تخصصی

پس از تسلط بر مسیر عمومی، لازم نیست همهٔ حوزه‌های بیوشیمی را با عمق یکسان دنبال کنید. شاخه را بر اساس نیاز درسی، علاقه یا پروژه پژوهشی انتخاب کنید.

| شاخه | ترتیب پیشنهادی |
|---|---|
| تاخوردگی پروتئین و پروتئوستاز | بدتاخوردگی و تجمع ← شبکهٔ ⁦Hsp70⁩ |
| آنزیم‌شناسی و سینتیک | سینتیک آنزیمی ← پویایی ساختاری و فعالیت |
| زیست‌انرژی و اکسایش–کاهش | زنجیره تنفسی میتوکندری ← انتقال الکترون فتوسنتزی |
| متابولیسم کربوهیدرات | گلیکوژن ← هموستاز گلوکز کبدی |
| متابولیسم لیپید | قطرات چربی و جریان لیپید ← اسفنگولیپیدها |
| متابولیسم اسیدهای آمینه و نیتروژن | متابولیسم بین‌اندامی اسیدهای آمینه ← سنتز اوره |
| متابولیسم نوکلئوتید | تنظیم پویای pool نوکلئوتید ← نوکلئوتیدهای میتوکندری |
| یکپارچگی و تنظیم متابولیسم | ⁦AMPK⁩ ← متابولیت‌ها به‌عنوان پیام‌رسان |
| گلیکوبیولوژی | glycocode ← بلوغ پروتئین وابسته به ⁦N-glycan⁩ |
