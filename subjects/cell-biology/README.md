# زیست‌شناسی سلولی | ⁦Cell Biology⁩

این صفحه یک **مسیر یادگیری نظری** برای زیست‌شناسی سلولی است؛ از پیش‌نیازهای پایه تا مطالعه پیشرفته و ورود به شاخه‌های تخصصی.  
هدف، فهرست‌کردن کتاب و مقاله نیست؛ باید بتوانید بفهمید **از کجا شروع کنید، هر منبع را چرا بخوانید، چگونه از آن استفاده کنید و قدم بعدی چیست**.

> **دامنه:** فقط منابع نظری. پروتکل، راهنمای آزمایشگاهی، ⁦SOP⁩ و آموزش عملی در این مسیر وارد نمی‌شوند.

# شاخه‌های تخصصی

در این مرحله مسیر خطی تمام می‌شود. لازم نیست همه شاخه‌ها را با یک عمق بخوانید؛ بر اساس درس، علاقه یا پروژه پژوهشی وارد شاخه مناسب شوید.

| شاخه | ترتیب پیشنهادی |
|---|---|
| غشا و انتقال | ناقل‌های ⁦ABC⁩ ← عدم‌تقارن لیپیدی |
| زیست‌شناسی اندامک‌ها و انتقال درون‌سلولی | ⁦COPII⁩ و مسیر ترشحی ← تماس‌های غشایی میان اندامک‌ها |
| هسته و انتقال هسته‌ای | انتقال هسته‌ای ← ساختار و مونتاژ ⁦NPC⁩ |
| پیام‌رسانی سلولی | کتاب تخصصی پیام‌رسانی ← سیگنالینگ کلسیم و میتوکندری |
| اسکلت سلولی و مکانیک سلول | مکانیک رشته‌ها ← موتورهای ⁦kinesin⁩ |
| چرخه و تقسیم سلولی | کنترل چرخه ← ⁦centromere⁩ و ⁦kinetochore⁩ |
| مرگ سلولی و اتوفاژی | مسیرهای مرگ تنظیم‌شده ← اتوفاژی انتخابی |
| چسبندگی و ماتریکس خارج‌سلولی | ماتریکس خارج‌سلولی ← ⁦adherens junction⁩ |
| ساختارهای اختصاصی سلول گیاهی | دیواره سلولی ← ⁦plasmodesmata⁩ |
