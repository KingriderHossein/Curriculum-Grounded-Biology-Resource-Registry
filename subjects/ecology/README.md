# اکولوژی | ⁦Ecology⁩

این صفحه یک **مسیر یادگیری نظری اکولوژی** است؛ از مفاهیم پایهٔ محیط و جمعیت تا جامعه، شبکه‌های غذایی، اکوسیستم، فضا و تغییرات جهانی.  
هدف این نیست که فقط فهرستی از کتاب‌ها و مقاله‌ها ارائه شود؛ باید روشن باشد **از کجا شروع کنید، هر منبع را چرا بخوانید، چگونه از آن استفاده کنید و بعد از آن به کجا بروید**.

> **دامنه:** فقط منابع نظری. پروتکل، راهنمای میدانی، دستورالعمل نمونه‌برداری، ⁦SOP⁩ و آموزش عملی در این مسیر وارد نمی‌شوند.

**مناسب برای:** دانشجویی که رشد جمعیت و پارامترهای جمعیت‌شناختی را می‌داند و می‌خواهد بفهمد داده‌های بلندمدت چگونه درک ما از دینامیک جمعیت را تغییر داده‌اند.

**دلیل انتخاب:** مطالعات میدانی بلندمدت را برای فهم بقا، تولیدمثل، تغییرات زمانی و پاسخ جمعیت به محیط جمع‌بندی می‌کند و فاصله میان مدل ساده و جمعیت واقعی را نشان می‌دهد.

**ادامه مسیر:** برای محیط‌های چندعاملی و پیش‌بینی جمعیت در شرایط متغیر، مرور جدیدتر جمعیت‌شناسی گیاهی را بخوانید.
