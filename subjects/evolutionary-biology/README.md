# زیست‌شناسی تکاملی | ⁦Evolutionary Biology⁩

این صفحه یک **مسیر یادگیری نظری زیست‌شناسی تکاملی** است؛ از شواهد و منطق تکامل تا انتخاب طبیعی، ژنتیک جمعیت، تبارزایی، گونه‌زایی، ماکروتکامل، تکوین تکاملی و تکامل انسان.  
هدف این است که بدانید **از کجا شروع کنید، هر منبع را چرا بخوانید، چگونه از آن استفاده کنید و بعد از آن به کجا بروید**.
