# هماتولوژی — ⁦Hematology⁩

این نقشه‌راه هماتولوژی را به‌عنوان **زیست‌شناسی و پاتوفیزیولوژی خون و بافت‌های خون‌ساز** می‌بیند. درمان، نسخه‌نویسی، الگوریتم تشخیصی، پروتکل انتقال خون و آموزش عملی آزمایشگاه هدف این مسیر نیستند.
