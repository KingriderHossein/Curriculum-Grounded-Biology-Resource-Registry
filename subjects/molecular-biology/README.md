# زیست‌شناسی مولکولی | ⁦Molecular Biology⁩

این صفحه یک **مسیر یادگیری نظری زیست‌شناسی مولکولی** است؛ از جریان اطلاعات ژنتیکی تا ماشین‌های مولکولی همانندسازی، رونویسی، پردازش ⁦RNA⁩، ترجمه، تنظیم ژن و سازمان ژنوم.  
هدف این است که بدانید **از کجا شروع کنید، هر منبع را چرا بخوانید، چگونه از آن استفاده کنید و بعد از آن به کجا بروید**.

> **دامنه:** فقط منابع نظری. پروتکل، راهنمای آزمایشگاهی، ⁦SOP⁩، آموزش ⁦wet-lab⁩ و دستورالعمل عملی تکنیک‌ها در این مسیر وارد نمی‌شوند.
