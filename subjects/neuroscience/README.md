این نقشه‌راه فقط منابع **نظری** را پوشش می‌دهد. هدف، فهم سلول عصبی، پیام‌رسانی، مدارها، سامانه‌های حسی و حرکتی، یادگیری، خواب و شناخت است؛ نه آموزش اجرای آزمایش، کدنویسی یا درمان بیماری.
